How it works

  1. Solari sandbox: Hosts the practice site. Streamly+ is a fake streaming service. It uses the same cancellation traps as real companies.
  2. Solari browser: Does the clicking. It runs in stealth mode and records the whole session. For a real service, it can use a saved login and a proxy in another country.
  3. Claude: Decides each step. It reads the page and picks the next click. It records every dark pattern and quotes the exact wording.
  4. Score: Starts at 100. Each dark pattern costs points. Extra clicks and extra time cost points too.
  5. Replay: The Solari recording becomes the replay. Each charge is marked at the moment it happened.

Run it yourself

You need Node 22 or newer, a Solari API key and an Anthropic API key.

git clone https://github.com/IamDejman/hotel-california
cd hotel-california
npm install
cp .env.example .env   # add both keys
npm start -- gym
npm run site

To score a service you pay for, follow the README.
